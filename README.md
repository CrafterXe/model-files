# model-files · J1 语音模型仓库

存放 **J1 本地AI陪伴** 项目所需的语音合成（TTS）模型权重。

这些文件体积较大，不适合放在主代码仓库，故单独存放于此，供安装脚本自动下载。

## 文件清单

| 文件 | 大小 | 作用 | 必需 |
|------|------|------|------|
| `s1v3.ckpt` | ~148 MB | **GPT 预训练底模**（v3）。负责把文本转成读音序列，是语音可懂度的关键。必须用官方预训练版，不要用微调版。 | ✅ |
| `sf_e8_s144.pth` | ~129 MB | **SoVITS 音色模型**（sweetiefox 微调，v2Pro）。决定说话的音色音质。 | ✅ |

> 两个文件缺一不可。放置位置：J1 项目的 `voice_model/` 目录下。

## 下载方式

**方式一：随安装脚本自动下载（推荐）**

J1 项目的 `install.bat` 会自动从本仓库的 Release 下载这两个文件并放到位，无需手动操作。

**方式二：手动下载**

到 [Releases](../../releases) 页面下载两个文件，放进 J1 项目的 `voice_model/` 目录：

```
J1项目/
└─ voice_model/
    ├─ s1v3.ckpt      ← 放这里
    └─ sf_e8_s144.pth  ← 放这里
```

## 关于音色训练（可选）

本仓库的音色模型由 `sweetiefox` 英文人声微调而来。

如果你想训练自己的音色，J1 项目内的 `training audio/` 目录提供了示例训练音频，配合 GPT-SoVITS 引擎可完成微调。注意：

- 底模 `s1v3.ckpt` 建议始终用官方预训练版（微调 GPT 容易降低可懂度）。
- 只微调 SoVITS 音色模型即可，训练数据建议 1 分钟以上、单一人声、无背景音。
- 训练对显存要求较高（建议 12GB+），8GB 显存请谨慎尝试。

## 说明

- 引擎（GPT-SoVITS 推理引擎，约 8GB）不在本仓库，由安装脚本从官方渠道下载。
- 本仓库仅存放上述两个语音权重文件。
